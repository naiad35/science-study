1여러 가지 힘

1. 힘이란?

  • 힘: 물체의 모양이나 운동 상태(빠르기·방향)를 변하게 하는 원인
  • 힘의 단위: N(뉴턴)
  • 힘의 3요소: 크기, 방향, 작용점 → 화살표로 표현
💡 화살표로 힘 나타내기 • 화살표 길이 = 힘의 크기 (길수록 센 힘)
• 화살표 방향 = 힘의 방향
• 화살표 시작점 = 작용점 (힘이 작용하는 위치)

2. 여러 가지 힘의 종류

힘정의방향예시
중력지구가 물체를 당기는 힘연직 아래 ↓물체가 떨어짐
탄성력변형된 물체가 원래로 돌아가려는 힘변형 반대 방향용수철, 고무줄
마찰력접촉면에서 움직임을 방해하는 힘운동 반대 방향브레이크
부력유체가 물체를 밀어 올리는 힘위쪽 ↑배가 뜸
수직항력접촉면이 물체를 떠받치는 힘접촉면에 수직책상이 책 받침

3. 중력과 무게

  • 중력: 지구가 물체를 아래로 끌어당기는 힘
  • 무게: 물체에 작용하는 중력의 크기 (단위: N)
  • 무게 = 질량 × 9.8 (지구에서)
📌 계산 예시 질량 5kg → 무게 = 5 × 9.8 = 49N
달에서는 중력이 지구의 1/6 → 무게도 1/6

4. 질량 vs 무게 ⭐시험 단골

구분질량무게
뜻물질의 고유한 양중력의 크기
단위kg, gN
측정도구양팔저울, 윗접시저울용수철저울
장소 따라안 변함변함 (달=1/6)
💡 쉽게 구별하기 질량 = 내 몸에 있는 살과 뼈의 양 (어디서나 똑같음)
무게 = 지구가 나를 당기는 힘 (달에선 가벼워짐)

5. 탄성력과 훅의 법칙

  • 탄성력: 변형된 물체가 원래 모양으로 돌아가려는 힘
  • 방향: 힘을 준 방향과 반대
  • 훅의 법칙: 늘어난 길이 ∝ 매단 무게 (정비례)
📌 훅의 법칙 계산 100g → 2cm 늘어남. 300g이면?
→ 무게가 3배니까 길이도 3배 = 6cm
연결 방법늘어난 길이
직렬 (한 줄)각각의 합 (더 잘 늘어남)
병렬 (나란히)한 개의 절반 (덜 늘어남)

6. 마찰력

  • 마찰력: 접촉면에서 움직임을 방해하는 힘
  • 커지는 조건: 물체가 무거울수록, 바닥이 거칠수록
  • ❗ 접촉면 넓이는 상관없음 (시험 함정!)
마찰력 크게 (이용)마찰력 작게 (감소)
타이어 홈, 눈길에 모래윤활유, 베어링, 왁스
⚠️ 정지 마찰력 vs 운동 마찰력 최대 정지 마찰력 > 운동 마찰력
→ 처음 밀 때가 가장 힘들고, 움직이기 시작하면 더 쉬움!

7. 부력

  • 부력: 물(유체)이 물체를 위로 밀어올리는 힘
  • 부력 > 중력 → 뜬다 / 부력 < 중력 → 가라앉는다
  • 부력은 잠긴 부피에 비례 (깊이는 상관없음!)
⚠️ 시험 함정 "더 깊이 들어가면 부력이 커지나요?" → 아니요!
완전히 잠기면 깊이가 달라도 부력은 같아요.

8. 합력(알짜힘) 계산 ⭐시험 필수

💡 알짜힘이란? 물체에 작용하는 모든 힘을 합친 것 = 합력 = 알짜힘
줄다리기처럼 생각! 양쪽 힘을 비교해서 "결국 어디로 얼마나"
상황계산예시
같은 방향더하기→5N + →3N = →8N
반대 방향빼기 (큰쪽-작은쪽)→5N + ←3N = →2N
크기 같고 반대= 0 (평형)→5N + ←5N = 0N

9. 힘의 평형

  • 힘의 평형: 알짜힘 = 0인 상태
  • 조건: 두 힘의 크기 같고, 방향 반대, 같은 작용선
  • 평형이면 → 정지 또는 등속 직선 운동 유지
📌 평형의 예 책상 위 책: 중력(↓) = 수직항력(↑) → 알짜힘 0 → 정지
물에 뜬 튜브: 중력(↓) = 부력(↑) → 알짜힘 0 → 떠 있음
⚠️ 주의! 알짜힘 0 ≠ 힘이 없다!
힘은 작용하고 있지만, 서로 상쇄되어 효과가 0인 것

10. 알짜힘과 운동 상태 변화 ⭐⭐핵심

💡 핵심 규칙 • 알짜힘 = 0 → 운동 상태 유지 (정지 또는 등속)
• 알짜힘 ≠ 0 → 운동 상태 변함 (속력이나 방향 바뀜)
힘과 운동방향힘의 방향변하는 것예시
나란 (같은 방향)운동 방향과 같음속력 증가자이로드롭, 스카이다이빙
나란 (반대 방향)운동 방향과 반대속력 감소위로 던진 공, 브레이크
수직 (90°)원의 중심 방향방향만 변함 (속력 일정)인공위성, 대관람차, 회전목마
비스듬운동 방향과 비스듬속력 + 방향 모두 변함바이킹, 그네, 던진 공
📌 등속 원운동 (방향만 변함) • 속력: 일정 / 방향: 매 순간 변함
• 힘의 방향: 원의 중심 방향으로 계속 작용
• 예: 인공위성, 대관람차, 회전목마, 선풍기 날개
📌 포물선 운동 (속력+방향 모두 변함) 힘(중력)이 운동 방향과 비스듬하게 작용 → 곡선 경로

① 비스듬히 던져 올린 물체
• 비스듬히 던진 공, 야구공, 축구공
• 활시위를 떠난 화살
• 힘의 방향: 항상 연직 아래 (중력)

② 실에 매달려 왕복하는 물체
• 바이킹, 그네, 시계추
• 힘의 방향: 항상 연직 아래 (중력)
⚠️ 자주 틀리는 것 "인공위성은 속력이 일정하니까 알짜힘=0?" → 틀림!
방향이 계속 변하니까 알짜힘 ≠ 0 (원의 중심으로 힘 작용 중)
2물질의 상태 변화

1. 물질의 세 가지 상태

상태모양부피입자 배열입자 사이 거리
고체일정일정규칙적, 촘촘매우 가까움
액체변함일정불규칙적조금 멂
기체변함변함매우 불규칙매우 멂
💡 기체만 압축이 잘 되는 이유 입자 사이 거리가 멀어서 누르면 가까워질 수 있음!
고체·액체는 이미 가까워서 압축 안 됨

2. 확산과 증발

  • 확산: 입자가 스스로 퍼져나가는 현상 (냄새가 퍼짐)
  • 증발: 액체 표면에서 기체로 변하는 현상 (빨래 마름)
  • 둘 다 온도가 높을수록 빠름

3. 상태 변화의 종류 (6가지) ⭐필수 암기

변화이름열에너지예시
고체→액체융해흡수얼음이 녹음
액체→고체응고방출물이 얼음 됨
액체→기체기화흡수물이 끓음, 빨래 마름
기체→액체액화방출컵 표면 물방울
고체→기체승화흡수드라이아이스
기체→고체승화방출성에
💡 외우는 꿀팁 융해 = 녹아서 흐물 / 응고 = 굳는다
기화 = 기체 됨 / 액화 = 액체 됨
승화 = 액체 단계를 건너뜀!

4. 상태 변화와 열에너지 ⭐시험 단골

💡 핵심 규칙 • 입자를 자유롭게 (고→액→기): 열 흡수 → 주변 시원
• 입자를 가두기 (기→액→고): 열 방출 → 주변 따뜻
열 흡수 (주변 시원)열 방출 (주변 따뜻)
융해, 기화, 승화(고→기)응고, 액화, 승화(기→고)
📌 열 흡수 예시 (시원해짐) • 음료수에 얼음 넣으면 시원 (융해)
• 물놀이 후 물 밖에서 추움 (기화)
• 드라이아이스 근처가 시원 (승화)
📌 열 방출 예시 (따뜻해짐) • 이글루에 물 뿌리면 따뜻 (응고)
• 소나기 전 후텁지근 (액화)
• 눈 올 때 포근함 (승화)

5. 상태 변화 시 변하는 것 vs 안 변하는 것

변하지 않는 것 ❌변하는 것 ⭕
입자의 종류, 크기, 개수입자의 운동, 배열
물질의 성질, 질량입자 사이 거리 → 부피
⚠️ 물의 예외! 대부분 물질: 얼면 부피 감소
물: 얼면 부피 증가! (약 10%)
→ 수도관 터짐, 얼음이 물에 뜸

6. 녹는점, 끓는점, 어는점

  • 녹는점 = 어는점: 고체↔액체 변하는 온도 (물: 0℃)
  • 끓는점: 액체→기체 변하는 온도 (물: 100℃)
  • 같은 물질이면 양에 관계없이 일정

7. 가열 곡선과 냉각 곡선 ⭐그래프 해석

💡 핵심 포인트 • 수평 구간 = 상태 변화 중 (온도 안 변함)
• 기울어진 구간 = 온도 변화 중
• 수평 구간에서 열은 상태 변화에 사용됨
구간상태온도열 사용
기울어짐 ↗한 가지 상태올라감온도 상승
수평 ━두 상태 공존일정상태 변화
⚠️ 자주 나오는 질문 "열을 주는데 왜 온도가 안 올라가요?"
→ 열이 온도 올리는 데 안 쓰이고 상태 변화에 쓰이는 중!
