🎯 힘의 작용과 운동 상태 변화

💪 알짜힘이 뭐야?

알짜힘 = 물체에 작용하는 모든 힘을 다 합친 것

🔑 핵심 공식
알짜힘 = 힘들의 합력 (같은 방향은 더하고, 반대 방향은 빼기!)
📌 예시
오른쪽 50N, 왼쪽 30N이 작용하면?
→ 알짜힘 = 50 - 30 = 20N, 오른쪽

🎢 알짜힘에 따른 운동

알짜힘 물체의 운동 예시
= 0 정지 유지
또는 등속 직선 운동		 에스컬레이터, 모노레일
≠ 0 운동 상태 변함
(속력·방향 중 하나 이상)		 떨어지는 공, 원운동
⚠️ 헷갈리지 마!
알짜힘 = 0이면 "가만히 있거나, 일정하게 움직임"
알짜힘 ≠ 0이면 "빨라지거나, 느려지거나, 방향이 바뀜"

🧭 힘의 방향과 운동 변화

알짜힘이 운동 방향과 어떻게 작용하느냐에 따라 달라져요!

힘과 운동 방향 변하는 것 예시
나란 (같은 방향) 속력 ↑ 자이로드롭, 스카이다이빙
나란 (반대 방향) 속력 ↓ 위로 던진 공, 브레이크
수직 (90°) 방향만 변함 인공위성, 대관람차
비스듬 속력 + 방향 둘 다 바이킹, 그네, 던진 공

🚀 속력만 변하는 운동

힘이 운동 방향과 나란할 때 → 직선으로 움직이면서 빨라지거나 느려짐

📈 속력 증가 (힘 = 운동 방향)
• 자이로드롭에서 떨어지기
• 스카이다이빙
• 경사면 내려오는 수레
📉 속력 감소 (힘 ↔ 운동 반대)
• 위로 던진 공 (올라갈 때)
• 브레이크 밟은 차
• 굴러가다 멈추는 공

🎡 등속 원운동 (방향만 변함)

힘이 운동 방향과 수직(90°)일 때 → 속력은 그대로, 방향만 계속 바뀜

등속 원운동 특징
• 속력: 일정 ⭕
• 방향: 매 순간 변함 (원의 접선 방향)
• 힘의 방향: 원의 중심 방향으로 당겨짐
📌 등속 원운동 예시
🛰️ 인공위성    🎡 대관람차    🎠 회전목마    선풍기 날개
❌ 자주 틀리는 것!
"속력이 일정하니까 알짜힘 = 0이다" → 틀림!
방향이 변하면 운동 상태가 변한 거야. 그래서 알짜힘 ≠ 0

⚽ 속력+방향 모두 변하는 운동

힘이 운동 방향과 비스듬하게 작용 → 곡선(포물선)을 그리며 움직임

📌 포물선 운동 예시
• 비스듬히 던진 공 ⚽
• 활시위를 떠난 화살 🏹
• 바이킹 놀이기구 🎢
• 그네 타기
🔑 포물선 운동의 특징
• 올라갈 때: 속력 ↓
• 내려올 때: 속력 ↑
• 방향: 계속 바뀜 (곡선이니까!)

⚖️ 일상생활에서의 힘의 평형

물체가 정지해 있다 = 작용하는 힘들이 서로 상쇄 = 알짜힘 0

상황 평형을 이루는 힘
책상 위 책 중력(↓) = 수직항력(↑)
용수철에 매달린 추 중력(↓) = 탄성력(↑)
물에 뜬 튜브 중력(↓) = 부력(↑)

📝 시험 필수 암기!

⭐ 운동 상태 변화에 영향 주는 요인
• 알짜힘이 클수록 → 변화가 크다
• 질량이 작을수록 → 변화가 크다
